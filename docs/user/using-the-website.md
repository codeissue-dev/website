# Using the website

- `/` - public product website
- `/register` - create an account
- `/login` - sign in
- `/issues/new` - submit a product issue
- `/admin` - operations overview
- `/admin/inbox` - conversations
- `/admin/orders` - orders
- `/admin/integrations` - connected channels
- `/admin/events` - persisted and live events

Use the language select in the header or workspace toolbar. The selected locale is stored in the `codeissue-locale` cookie, so URLs stay unchanged.
